How the implied value works

Implied value = TVL × peer ratio × growth × maturity × breadth

Peer ratioMedian market-cap/TVL of tokenized protocols in the same category (peers ≥ $20M TVL, winsorized 0.02–3.0), shrunk toward the global median by peer count: (n·median + 4·global)/(n+4). Global median here: —×.
Growth1 + clamp(change_7d, −30%, +30%) × 0.6 → 0.82–1.18. Momentum is rewarded, spikes are capped, missing data is neutral.
Maturity0.80 + 0.40 × min(age, 3 yrs)/3 yrs. Longer running with no token = longer proven record.
Breadth1 + 0.03 per extra chain, max +15%. Multichain reach is launch-day distribution.
