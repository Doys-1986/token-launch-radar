A token launch radar built from a sealed DefiLlama snapshot. It finds the protocols that record no token yet, estimates what each one's launch would be worth from the market-cap/TVL ratios of comparable tokenized protocols in the same category — adjusted for TVL trend, protocol age, and chain breadth — and ranks 200 of them, every row with its full workings and a step-by-step plan to farm it. The static dashboard in `dashboard/` renders the board with no network: sortable, filterable, with a detail view for every protocol.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <snapshot.json>
```
